# recursos-informaticos-ASF

Este proyecto trata sobre crear y editar archivos en Github, crear repositorios tanto públicos como privados, gestionar colaboradores, realizar un fork de un repositorio público, crear y gestionar ramas, crear una pull request, revertir un commit, resolver un conflicto, publicar la página web, crear una versión y documentar el proyecto, utilizar incidencias y seguimiento del trabajo.
